# Shared editor fonts

Unmodified Liberation Sans and Mono 2.1.5.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

The included LICENSE applies to these fonts (SIL Open Font License 1.1); it is separate from the Rust code license. Skia and the browser load these exact bytes so native input geometry does not depend on device font substitutions. System fallback fonts still handle characters absent from Liberation.
